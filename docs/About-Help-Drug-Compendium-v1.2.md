# Anaesthesia & ICU Drug Compendium

**Version 1.2 (Nov 2026)** · 100 drugs · Works offline · Free ([GPL-3.0](https://www.gnu.org/licenses/gpl-3.0.html))

Author: Prof. Jyotirmay Kirtania

A single-file HTML app: `Drug-Compendium.html`. No installation, no account, no internet needed once saved.

## Why use it

Open it every day. Recall a dose from memory, then check it in the app. Within weeks the common drugs stay in your head. Use it to look up rarely used drugs and uncommon indications when you need them.

## Three key features

1. **Find any drug fast.** Type a drug name, a US name (`lidocaine`, `epinephrine`), an abbreviation (`TXA`, `LAST`, `MH`) or a word like `renal` or `children`.
2. **One-tap sections.** The buttons **All**, **Name**, **Uses**, **Contra**, **Dose**, **ADR** show only that part of the drug page. Use **Dose** for dose by age and kidney or liver function.
3. **Built for the bedside.** Adult and paediatric doses side by side, with warnings, interactions and the source document for each drug. Works without the internet once saved.

## Quick start

### Android phone or tablet

1. Download `Drug-Compendium.html` from this repository. Wait for the download to finish.
2. Tap the file again and choose **Chrome**. The app opens.
3. Quick access every day:
   - In Chrome, tap **⋮** and then the **☆** star. The app is saved in Bookmarks.
4. If the file will not open: open the **Files** app, then **Downloads**, tap the file and choose **Chrome**.

### iPhone or iPad

1. Tap the file, then the **Share** icon, then **Save to Files** → **On My iPhone** → **Save**.
2. The Files app preview may not run the search and tabs. For the full app on iPhone, use the web link if one has been shared.
3. With the link: open it in **Safari**, tap **Share**, then **Add to Home Screen**. The app now has its own icon.

### PC or laptop

1. Download the file from this repository.
2. Open your Downloads folder and double-click the file. It opens in Chrome or Edge.
3. Quick access: press `Ctrl` + `D` to bookmark it. Or right-click the file → **Send to** → **Desktop (create shortcut)**.
4. Tip: press `/` on the keyboard to jump to the search box.

## Daily 2-minute habit

Pick one drug before your list. Say its dose and main contraindication aloud. Then tap **Dose** and **Contra** to check. Repeat daily.
