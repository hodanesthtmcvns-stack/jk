CCRA Lean

ICU records · MPMMCC & HBCH · stored on this PC only

Open a patient by case number

Each patient has one record on this PC. Enter demographics and diagnoses once; every note reuses them.

  1. Type the case number in the left panel and press Open, or select New patient. Nothing is stored until you create the record.
  2. Complete the patient record (diagnoses, allergy, goal of care, devices).
  3. Choose a note. Amber fields were carried from the last note: check or change them.
  4. Finalise to save the note, then copy it into CIS or print it.

Records live in this browser profile. Export a backup regularly and keep this file at one fixed location on the PC.
